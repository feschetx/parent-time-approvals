# Parent time approvals

Static parent signing page with clear extra-time and decline buttons. Contains no embedded account data, secrets, usage records or signing keys.
Signing keys are generated on the parent device and stored encrypted. Existing saved keys are preserved across page updates.

When an HTTPS delivery service is configured, signed decisions are delivered automatically and confirmation waits for a receipt from the PC. Otherwise the page clearly uses the signed email-reply fallback. Passwords and private signing keys never leave the parent device.
