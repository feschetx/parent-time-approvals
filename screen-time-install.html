Daily Screen Time

One-time setup on the monitored iPhone. After setup, no daily photos or copying are needed.

1. Add the shortcut

This reads yesterday’s app names and Apple-reported durations from the phone you select, then sends them over HTTPS to your private family collector for the monitoring report.

Open the private QR code provided on your desktop to enable setup.

Download Daily Screen Time
  1. Tap Copy private setup code above.
  2. Download the shortcut. Open it from Safari Downloads or Files, then choose Add Shortcut.
  3. When asked for the setup code, paste it. When asked for a device, choose this iPhone’s name, never All Devices.
  4. Run Daily Screen Time once. Allow Screen Time access and sending app activity to family-screen-time-collector.feschetx-family-time.workers.dev if prompted.

Then tell the setup chat “first run done”. It will check delivery directly. If the phone shows an error, give that message; you do not need to copy usage data.

2. Make it automatic

After the first run is confirmed:

  1. In Shortcuts, open Daily Screen Time → Edit → Automation → Time of Day.
  2. Choose 07:45 and Daily. Enable the automation and choose to run without asking (turn off Confirm Before Run, or choose Run Immediately, if shown).
  3. In the shortcut editor, tap ⓘ → Privacy and enable Allow Running When Locked. Save.

If your phone instead has the older Automation → + layout, choose Time of Day → 07:45 → Daily → Run Immediately, then select Daily Screen Time (or add Run Shortcut and select it).

Keep the phone on Hong Kong time. This runs before the 08:30 report. The setup chat still needs to verify a scheduled run while the phone is locked; installing the shortcut alone does not verify that. During setup, the chat may guide a short scheduled test before you save the daily time.

Layout reference: Apple’s iOS 27 automation guide.

What this covers

App activity only. It does not read messages, photos, browser URLs or video titles, and it does not change limits, blocking or accounts. Apple’s figures remain separate from Qustodio’s; neither is independently verified attention. Empty or failed readings are unavailable data, not zero use.

Your setup code can upload only; it cannot download reports. Keep this private link and code private. This generic page does not upload your code or contain usage records. Version 1.
