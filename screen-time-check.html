Check this iPhone’s Screen Time

A one-time check before automatic reports are enabled.

  1. Open this page in Safari on the iPhone.
  2. Tap Add setup shortcut below. Choose this iPhone when asked for a device; avoid “All Devices”. Then add the shortcut.
  3. In Shortcuts, tap Screen Time Setup Check. Allow the Screen Time request if shown.
Add setup shortcut

If the button does not open Shortcuts, download the signed shortcut file, open it from Safari’s Downloads, and add it to Shortcuts.

What it does: reads today’s app names and durations for the device you choose, displays them, and copies the report to the iPhone clipboard. An empty result means data is unavailable, not zero usage.

It uploads nothing, changes no limits, and does not read messages, photos, video titles or website history. This test does not yet enable daily collection.

Version 1 · Requires iOS 26 or later · Signed using Apple’s Shortcuts tool. You can inspect the actions before adding it.
